# 系统启动命令记录

## 生产启动（标准命令）

```bash
cd /Users/yushui/Desktop/钉钉消息/dingtalk_script
PATH="$HOME/.workbuddy/binaries/node/cli-connector-packages/bin:$PATH" \
  python main.py --mode PRODUCTION
```

- 使用生产群配置 `data/groups.json`（31 群）
- `PATH` 前缀确保能找到 `dws` CLI（本机安装在 workbuddy 目录，不在默认 PATH）
- `.env` 会被自动加载（LLM/VISION/SLA 配置）

## 其他模式

```bash
# 辅助模式（模型来源动作一律需人工确认）
python main.py --mode ASSISTED

# 影子模式（只记录语义决策，不执行、不发通知）
python main.py --mode SHADOW

# 测试群配置（data/group-test.json）
python main.py --test

# 指定群配置文件
python main.py --groups-config /path/to/groups.json
```

## 依赖前置

- Python 3.13+，虚拟环境 `.venv/`（`pip install -r requirements.txt`）
- `dws` CLI 已登录钉钉账号（`dws auth` 检查）
- `.env` 含 `LLM_*`、`VISION_*` 密钥（不入库）
