# 系统启动命令记录

## 一键启动 / 关闭（推荐）

```bash
cd /Users/yushui/Desktop/钉钉消息/dingtalk_script

# 一键启动：主系统(502群) + 管理后台(8899端口，无密码)
bash manage.sh start
# 或
bash start.sh

# 一键关闭：同时停止主系统 + 管理后台
bash manage.sh stop
# 或
bash stop.sh

# 只启动/停止其中一个
bash manage.sh start-main   # 仅主系统
bash manage.sh start-admin  # 仅管理后台 http://127.0.0.1:8899
bash manage.sh stop-main
bash manage.sh stop-admin

# 其他
bash manage.sh status   # 查看运行状态、pid、端口
bash manage.sh logs     # 看最近 50 行日志
bash manage.sh restart  # 重启全部
```

- `manage.sh` 已自动处理：`PATH` 加上 `dws` CLI、` .venv` 激活、后台 `nohup`、pid 文件 `data/*.pid`、日志 `logs/*.log`
- 管理后台默认**无密码直接访问** `http://127.0.0.1:8899`，如需加密码：
  ```bash
  ADMIN_PASSWORD=你的密码 bash manage.sh start
  # 或
  ADMIN_PASSWORD=xxx ADMIN_PORT=8899 bash manage.sh start-admin
  ```
- 日志：`tail -f logs/app.log`（主系统） / `tail -f logs/admin.log`（管理后台）

## 生产启动（标准命令，等同 manage.sh 的底层）

```bash
cd /Users/yushui/Desktop/钉钉消息/dingtalk_script
PATH="$HOME/.workbuddy/binaries/node/cli-connector-packages/bin:$PATH" \
  .venv/bin/python main.py --mode PRODUCTION

# 管理后台单独启动（无密码）
python3 admin/server.py --port 8899
# 带密码
ADMIN_PASSWORD=xxx python3 admin/server.py --port 8899
```

- 使用生产群配置 `data/groups.json`（31 群）
- `PATH` 前缀确保能找到 `dws` CLI（本机安装在 workbuddy 目录，不在默认 PATH）
- `.env` 会被自动加载（LLM/VISION/SLA 配置）

## 其他模式

```bash
# 辅助模式（模型来源动作一律需人工确认）
.venv/bin/python main.py --mode ASSISTED

# 影子模式（只记录语义决策，不执行、不发通知）
.venv/bin/python main.py --mode SHADOW

# 测试群配置（data/group-test.json）
.venv/bin/python main.py --test

# 指定群配置文件
.venv/bin/python main.py --groups-config /path/to/groups.json
```

## 依赖前置

- Python 3.13+，虚拟环境 `.venv/`（`pip install -r requirements.txt`）
- 管理后台需 `fastapi`+`uvicorn`：`manage.sh` 会自动按 `.venv` → `/opt/homebrew/bin/python3` → `python3` 顺序挑选装了它们的解释器（2026-09-03 修复：终端激活 `.venv` 时裸 `python3` 会被遮蔽，故加显式绝对路径兜底）；启动时会打印 `解释器=...`，可在 `logs/admin.log` 核对
- `dws` CLI 已登录钉钉账号（`dws auth` 检查）
- `.env` 含 `LLM_*`、`VISION_*` 密钥（不入库）
